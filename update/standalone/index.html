📋 门店报货汇总回填工具

把品牌叫货单（汇总明细txt / 太二送货单 xlsx / 费大厨合单 xlsx）与 HDL 叫货单（历史订单txt / 报货转录txt / 报货xlsx / 普通门店叫货单xlsx）的报货数据，汇总成「门店分类统计」，并按右侧对应关系回填到杭州 / 上海配货单的「报货量」列，HDL 门店的要货明细同步写入「备注」列（加粗 10 号字）。未查到匹配门店视为当天未叫货。所有文件均在本地处理，不会上传。

📖 使用方法 ＆ 功能简介（点开查看）

三步使用：① 蓝色区（区域①）拖入当天叫货单（汇总明细txt / 太二送货单 xlsx / 费大厨合单 xlsx / HDL txt / HDL 报货xlsx，可多选）；② 橙色区（区域②）拖入要回填的杭州配货单 / 上海配货单（当前为「秋季决定版」，空表也行）；③ 页面自动汇总回填后，每份配货单点「暂存」进暂存工作区，在暂存区统一选好标题日期后，点橙色大按钮导出——导出前会自动与叫货单数据逐格对照，全部一致才放行下载；汇总表仍在「导出结果」区直接导出。另有红色「🥩 三大肉窗口」：只拖入配货单（无需叫货单），拖入后先在下方「选择适用 sheet」面板勾选本文件适用三大肉规则的 sheet（未勾选的完全不动），再点开始调整重写备注列，结果同样进暂存工作区统一导出。

功能简介：

  • 自动汇总：各格式叫货单统一成「门店分类统计」格式，数量自动斤÷2换算成公斤；
  • HDL 报货 xlsx（日常主流程）：列头「N号」+上午/下午成对列组，直接把 xlsx 拖入即可；自动取与执行当天同日的日期列（上午列填上午 sheet、下午列填下午 sheet），单元格自带的一配/二配、合计/共计都会自动剥除按品项重新合计；
  • HDL 门店订单 txt（历史格式）：每行一家门店、自动取「最后一列非空订单」为当天要货；备注列写入要货明细原文，报货量列自动算各品项合计（公斤），SUM 公式行不动；品名写法不强制统一（肥胖/肥拼、胸口油/胸口朥等都按原文保留）；
  • HDL 报货图片转录 txt：按「门店：／人员：／上午：／下午：」分行填写，上午列填配货单上午 sheet、下午列填下午 sheet（自动识别），报货量按各品项重量合计、无视自带的 合计/共计 行，备注列固定加粗 10 号字；HDL 门店的匹配记忆与品牌门店分开存放、互不影响；
  • 自动回填：XXJ→巡湘记、YYX→杨有喜、TE→太二、SHG→怂、FDC→费大厨；费大厨「匙肚」「牛胸腩」=「鲜牛前腿肉」；巡湘记组合牛肉自动拆到吊龙/排腩、匙仁/肥拼、大耳/腿肉；只写报货量/备注列，表格格式和公式全部保留，导出新副本不覆盖原文件；
  • 未叫货清零：当天没查到报货的门店自动清空旧数；已叫货门店里、当天没叫的品项格（如牛油/肋条）旧数同样清空，不会残留上一轮的数据（均可在导出选项关闭）；
  • 三类导出：回填单 / 门店分类统计汇总表 / 巡湘记杨有喜汇总表（后两者各有独立日期选项：报货当天或前一天）；
  • 门店匹配：规则识别 + 自动记忆 + 内置底账；新写法在点击「暂存」时弹窗请您确认，不对可直接录入正确门店；FDC/XXJ/YYX/TE 严格对应费大厨/巡湘记/杨有喜/太二，绝不跨品牌；HDL 门店按中文数字编号守卫匹配（“九十店”绝不会配到“九十二店”），编号相同但有 新字/后缀 差异时会请您确认；错配可在底部「门店对应关系」菜单（点「修改」）录入「写法 → 正确门店」永久纠正；嘉兴/浦东八佰伴等同名门店已精确区分；
  • 未报货清单：回填报告里列出所有当天未报货的门店及其所在工作表；
  • 防串数：混入两个日期的叫货单会红条警示，导出只按最新一天；
  • 备份当前版本：点标题右侧「💾 备份当前版本」按钮，自动把当前工具页面下载为带时间戳的备份文件（如 报货汇总工具-20260927-2130-备份.html），存入浏览器下载目录，随时可还原；
  • 导出门店记忆：点标题右侧「📦 导出全部门店记忆」按钮，把本机积累的全部门店对应（手动对应/弹窗确认/自动记忆/HDL记忆）导出为 JSON 文件——换电脑或重装浏览器后交给管理员并入工具内置底账；也可以直接在本页最下方「🔄 记忆迁移」面板把 JSON 放进来，本机立即继承全部记忆（两台电脑互导即同步）。
  • 格式记忆：底部「🗂 格式记忆」区的下拉显示当前记住的叫货单/配货单格式（内置支持 5 种叫货单 + 当前两份配货单模板），选中「收录」条目可点下方按钮删除；把文件拖进虚线框可「纳入」新格式或「替换」旧格式——配货单换新版时拖入新文件选「替换旧的配货单格式」即可；文件里有记忆中没有的新门店时，工具先自动记忆，再列出清单请您逐条确认是否准确。

      🐄 活牛需求计算器（一配/二配 · 推荐富裕净肉 / 活牛重量 / 推荐头数）
      
填写配次、订单量、胴体率、胴体均重、上一配次吊龙余 → 自动算出推荐富裕净肉、活牛放多少、推荐头数（头数按 胴体均重÷胴体率 折算单头活牛均重）。点「🧮 计算并保存」结果进下方历史记录；实际配送完成后点「📋 填实际」回填实际数据，积累的数据在底部「📊 数据汇总」一键复制给维护方修正公式系数。公式：一配=3295.3+0.3543×订单量−0.00001503×订单量²−2.77×吊龙余−5240.4×胴体率−0.8×均重（含多放牛补偿−18）；二配 吊龙余≤35：21.2+0.2274×订单量−24.20×√吊龙余；吊龙余＞35：33.3+0.1884×订单量−32.31×√吊龙余。净肉÷0.48→胴体，胴体÷胴体率→活牛。误差范围：一配±10kg、二配±21kg（2383一单为已知异常点）。
